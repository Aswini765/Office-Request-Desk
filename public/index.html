How this works (for the demo)

Trigger: clicking Submit starts a fixed pipeline; it is not a chat.

Gemini (AI) only reads the text: it picks LEAVE / EXPENSE / IT_SUPPORT / OTHER and pulls out fields such as dates and amounts. Missing facts stay null.

JavaScript (code) in src/rules.js applies the IF/THEN rules and sets the status. Rules are in code, not in the AI, because an AI can give different answers to the same input and can be talked into approving things; code is repeatable and auditable.

Human reviewer is needed for every status except Auto-approved and Standard support ticket: manager/finance approval, manual review/verification, escalations, and anything classified OTHER.

Google Sheets: the server POSTs {"tab","row"} to your Apps Script. Success is shown only if the reply contains ok: true.
